# Project instructions

- Keep the quiz in `index.html`, with inline CSS, JavaScript, and SVG.
- Do not add servers, packages, remote resources, or external dependencies.
- Preserve Korean UI text, ten questions, scoring, progress, and restart.
- Make only changes requested by the task; avoid unrelated refactoring.
- Preserve keyboard navigation, visible focus, screen reader feedback,
  system light/dark themes, and reduced-motion support.
- Check answer locking, scores, progress, results, and restart in a browser.
- Check narrow layouts and both color schemes when changing presentation.
- Keep the `.gitignore` publication allowlist; review staged files before
  publishing. Never include secrets or unrelated local files.
